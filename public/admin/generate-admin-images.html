How to use:
1. Open this file in a browser (npx serve public/ or double-click the HTML).
2. Click Generate on each card (or Generate All).
3. Puter.js will open a quick auth popup on first use — sign in or create a free account.
4. Once images appear, click Download PNG to save them.
5. Place downloaded files in public/admin/:
   • admin-hero-banner.png
   • admin-avatar-placeholder.png
